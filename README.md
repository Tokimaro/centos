# Albion Trader

Локальное приложение для поиска выгодных сделок в Albion Online: сравнивает цены
в городах и на Чёрном рынке и показывает, где купить и куда отвезти предмет.

Данные собирает **только ваш** [albiondata-client](https://github.com/ao-data/albiondata-client)
(клиент проекта The Albion Online Data Project). Он читает сетевой трафик игры,
когда вы открываете рынок, и отправляет увиденные заказы в это приложение.
Всё хранится в локальной базе `data/market.db`, публичные серверы AODP не
используются, а веб-интерфейс по умолчанию доступен только с вашего компьютера
(`127.0.0.1`).

```
Albion Online ──трафик──> albiondata-client ──HTTP POST──> Albion Trader ──> SQLite
                                   (-i http://127.0.0.1:8484)       │
                                                                   └──> браузер: сделки, цены
```

## Возможности

- **Город → город** и **город → Чёрный рынок**: Тетфорд, Лимхерст, Бриджвотч,
  Мартлок, Форт Стерлинг, Карлеон, Брецилиэн, порталы, логова контрабандистов.
- Налоги: 4% с премиумом / 8% без, 2,5% за размещение заказа.
- Режимы покупки: выкуп предложений или свой заказ на покупку. Режимы продажи:
  мгновенно в запросы или своим предложением (на Чёрном рынке только мгновенно).
- Учёт качества: запрос на качество *q* можно закрыть предметом качества *q* и выше
  (например, купить «Выдающееся» дешевле «Хорошего» и сдать на ЧР).
- Проход по стаканам: считается реальное количество, итоговая прибыль и вложения,
  а не только разница верхних цен.
- Фильтры: города, свежесть данных, мин. прибыль/маржа, тир, зачарование, поиск по
  названию (русские и английские названия).
- Страница цен предмета по всем рынкам и качествам, средний объём продаж в сутки
  (если в игре открывали график истории цен).
- Устаревшие данные: заказы с истёкшим сроком удаляются, а заказы, которые пропали
  из более свежего снимка стакана, считаются выкупленными.

## Установка

Нужен Python 3.10+ (сторонние библиотеки не нужны).

```sh
git clone <этот репозиторий> albion-trader
cd albion-trader
python -m albion_trader update-items   # один раз: названия предметов (RU/EN)
python -m albion_trader serve          # http://127.0.0.1:8484
```

В Windows можно просто запустить `start.bat`.

`update-items` только скачивает открытый справочник предметов из
[ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps); ваши данные
при этом никуда не отправляются. Без справочника вместо названий будут ID.

## Подключение albiondata-client

1. Установите клиент со страницы
   [релизов](https://github.com/ao-data/albiondata-client/releases).
2. Закройте уже запущенный клиент (в том числе из трея) — он по умолчанию
   отправляет данные на публичный сервер.
3. Запустите его, указав адрес Albion Trader в параметре `-i`:

   ```
   "C:\Program Files\Albion Data Client\albiondata-client.exe" -i http://127.0.0.1:8484
   ```

   Параметр `-i` **заменяет** публичный сервер, поэтому данные уходят только в
   ваше приложение. Готовый вариант — `start-client.bat` (поправьте в нём путь,
   если клиент установлен в другое место). Удобно создать ярлык с этой командой
   и убрать клиент из автозапуска.
4. Зайдите в игру и открывайте рынки нужных городов и Чёрного рынка (в Карлеоне).
   Каждый просмотр страницы рынка появляется во вкладке **Статус**.

### Токен (необязательно)

Чтобы в базу не могли писать другие программы на вашем ПК:

```sh
python -m albion_trader serve --token auto   # токен сохранится в data/token.txt
```

Адрес для клиента станет `http://127.0.0.1:8484/<токен>`; точная команда
показывается при запуске и во вкладке **Статус**.

## Как пользоваться

- **Сделки** — выберите, где покупать и где продавать, режимы и фильтры.
  Столбцы: цена покупки и продажи, прибыль за штуку (после налогов и комиссий),
  маржа, количество, которое можно провести с прибылью, итоговая прибыль,
  вложения, объём продаж в сутки и возраст самой старой из цен. Цифра в скобках
  в столбце «Кач.» — качество, которое нужно купить, если оно отличается.
  Клик по названию открывает сравнение цен предмета.
- **Цены предмета** — лучшие цены на каждом рынке по качествам.
- **Статус** — что и когда пришло от клиента.

Чем свежее данные, тем точнее сделки: цены на Чёрном рынке меняются быстро,
поэтому перед поездкой обновите рынки в игре. Приложение не учитывает вес груза и
риск перевозки через красные/чёрные зоны.

## Параметры

```
python -m albion_trader [--data-dir DIR] serve [--host 127.0.0.1] [--port 8484]
                                         [--token TOKEN|auto] [--retention-hours 72]
python -m albion_trader update-items
python -m albion_trader cleanup [--retention-hours 72]
```

- `--data-dir` (или `ALBION_TRADER_DATA`) — где лежат база и справочники.
- `--host 0.0.0.0` открывает доступ из сети; делайте это только вместе с `--token`
  и учитывайте, что веб-интерфейс паролем не защищён.
- `--retention-hours` — через сколько часов удалять заказы, которые больше не видели.

## Разработка

```sh
python -m unittest discover -s tests -v
```

Структура:

- `albion_trader/server.py` — приём `POST /<топик>` от клиента (`marketorders.ingest`,
  `markethistories.ingest`, `goldprices.ingest`), REST API и статика;
- `albion_trader/db.py` — схема SQLite, разбор пакетов, очистка;
- `albion_trader/deals.py` — расчёт сделок;
- `albion_trader/locations.py` — ID локаций → рынки;
- `albion_trader/items.py` — названия предметов;
- `albion_trader/static/` — веб-интерфейс.
